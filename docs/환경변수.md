# 환경변수 가이드

서버 루트 `.env` 설정 설명입니다.  
템플릿·기본값은 [`.env.example`](../.env.example)를 기준으로 합니다.

| 문서 | 역할 |
|------|------|
| `.env.example` | 복사용 템플릿 + 짧은 주석 |
| **이 문서** | 전체 키 의미·기본값·영향 범위 |
| [`사용법.md`](./사용법.md) | 시작에 꼭 필요한 값만 |

> `.env`는 git에 올리지 않습니다. 비밀값(`*_API_KEY`, `DB_PASSWORD` 등)은 운영 시 반드시 교체하세요.  
> 웹 대시보드용 Vite 변수는 `web/.env`이며, **서버 OpenAI 키를 넣지 마세요.**

## 11. Investigation 자동 생성

검색 Job 완료 후 AI Score가 임계값 이상인 매물만 Investigation으로 자동 생성합니다.

| 키 | 기본값 | 설명 |
|----|--------|------|
| `INVESTIGATION_AI_SCORE_THRESHOLD` | `90` | 0~100. `create_investigation` 규칙 seed 값 |
| `INVESTIGATION_AUTO_CREATE` | `true` | `false`면 자동 생성 안 함 |

예: 최종 AI Score 59%인 매물은 90 미만 → **연결 조사 없음**이 정상입니다.  
대시보드 Rules UI 또는 `AI_RULES_JSON`으로 임계값을 바꿀 수 있습니다.

| `AI_VISION_BEFORE_MATCH` | `true` | Matching 후 Vision으로 image 점수 보정 (**유료**) |

Matching 파이프라인(요약):

```
텍스트 Matching
  → (옵션) OCR
  → 로컬 이미지 게이트 (비용 0)   ← Color → pHash → LooksSame+SSIM+OpenCV
  → (통과 시만) ChatGPT Vision      ← AI_VISION_BEFORE_MATCH
  → Investigation 임계값 검사       ← INVESTIGATION_AI_SCORE_THRESHOLD
```

## 13. 로컬 이미지 게이트 (비용 절감)

`AI_VISION_BEFORE_MATCH=true`일 때, **유료 Vision 전에** 로컬 엔진으로 걸러냅니다.

```
전처리
  → Color (색이 확연히 다르면 Vision 스킵)
  → pHash (거의 같으면 Vision 스킵+고점 / 완전 다르면 스킵)
  → LooksSame + SSIM + OpenCV ORB
  → threshold 통과 시만 Vision
```

| 키 | 기본값 | 설명 |
|----|--------|------|
| `AI_LOCAL_IMAGE_GATE` | `true` | `false`면 로컬 게이트 없이 Vision만 (기존 동작) |
| `AI_LOCAL_COLOR_REJECT_THRESHOLD` | `35` | 색 유사도 미만 → Vision block |
| `AI_LOCAL_PHASH_REJECT_THRESHOLD` | `30` | pHash 미만 → Vision block |
| `AI_LOCAL_PHASH_PASS_THRESHOLD` | `90` | pHash 이상 → 거의 동일, Vision 스킵(고점수) |
| `AI_LOCAL_SSIM_THRESHOLD` | `75` | SSIM ≥ 이면 Vision 후보 (LooksSame 보완) |
| `AI_LOCAL_SSIM_PASS_THRESHOLD` | `92` | SSIM ≥ 이면 거의 동일, Vision 스킵(고점수) |
| `AI_LOCAL_LOOKS_SAME_THRESHOLD` | `70` | LooksSame ≥ 이면 Vision 후보 |
| `AI_LOCAL_OPENCV_THRESHOLD` | `60` | OpenCV ≥ 이면 Vision 후보 |
| `AI_LOCAL_LOOKS_SAME_STRICT` | `false` | looks-same strict 모드 |
| `AI_LOCAL_LOOKS_SAME_TOLERANCE` | `2.5` | non-strict ΔE tolerance |
| `AI_LOCAL_LOOKS_SAME_IGNORE_ANTIALIASING` | `true` | 안티앨리어싱 무시 |
| `AI_LOCAL_OPENCV_ORB_NFEATURES` | `500` | ORB feature 상한 |
| `AI_LOCAL_OPENCV_ORB_MATCH_RATIO` | `0.75` | Lowe ratio test |
| `AI_LOCAL_PREPROCESS_MAX_WIDTH` | `512` | 전처리 최대 가로 |
| `AI_LOCAL_PREPROCESS_MAX_HEIGHT` | `512` | 전처리 최대 세로 |
| `AI_LOCAL_PREPROCESS_BACKGROUND` | `ffffff` | 배경 정규화 색 |
| `AI_LOCAL_PREPROCESS_NORMALIZE` | `true` | sharp.normalize() |

Vision 후보 조건(OR): LooksSame ≥ 임계 **또는** SSIM ≥ 임계 **또는** OpenCV ≥ 임계.  
엔진 전부 실패(다운로드/라이브러리 오류)하면 Vision으로 fallback합니다.

> `feature/image-compare` 브랜치의 `COMPARE_*`(UI 비교 Drawer용)와는 **별개**입니다.  
> Matching 비용 절감은 위 `AI_LOCAL_*`만 보면 됩니다.

## 14. 자주 쓰는 튜닝

| 목적 | 설정 |
|------|------|
| AI 전부 끄기 | `AI_ENABLED=false` |
| Vision 비용만 끄기 | `AI_VISION_BEFORE_MATCH=false` |
| 로컬 게이트만 끄고 Vision 항상 | `AI_LOCAL_IMAGE_GATE=false` |
| Investigation 더 많이 생성 | `INVESTIGATION_AI_SCORE_THRESHOLD=70` (또는 Rules UI) |
| Investigation 자동 생성 끔 | `INVESTIGATION_AUTO_CREATE=false` |
| 색 필터 완화 | `AI_LOCAL_COLOR_REJECT_THRESHOLD=20` |
| pHash “거의 동일” 기준 완화 | `AI_LOCAL_PHASH_PASS_THRESHOLD=85` |
| SSIM Vision 후보 완화 | `AI_LOCAL_SSIM_THRESHOLD=65` |

변경 후 **API/Worker 재시작**이 필요합니다 (`r.bat` 재실행).
