## STEP MENU-09 — 최종 구조

**상태:** 완료

### 최종 Menu Tree

```text
Dashboard (/) — Overview
Search
├── 상품 검색 (/search)
├── 이미지 검색 (disabled)
├── 예약 검색 (disabled)
└── 검색 이력 (/history)
Rental
├── 계약 목록 (/rental?tab=contracts)
├── 자동 검색 (/rental?tab=auto)
└── 조사 이력 (/rental?tab=investigations)
Investigation
├── Open (?status=Open)
├── Reviewing (?status=Review)
├── Completed (?status=Completed)
└── Archived (?status=Archived)
Analytics
├── 검색 통계 (?section=search)
├── 사이트별 통계 (?section=sites)
├── AI 분석 통계 (?section=ai)
└── Investigation 통계 (?section=investigation)
System
├── Worker / Queue / API / Proxy / Scheduler / AI Engine / Prompt
```

### Routing

| Path | 화면 |
|------|------|
| `/` | OverviewPage |
| `/search` | 상품 검색 (Toolbar + Results) |
| `/history` | HistoryPage |
| `/rental` | RentalPage (+ tab) |
| `/investigation` | CaseListPage (+ status) |
| `/analytics` | AnalyticsPage (+ section) |
| `/system` | SystemPage (+ section) |

### Component

- Nav: `config/navigation.ts` → `AppSidebar`
- Shell: `AppShell` / `App.tsx` Routes
- Overview: `OverviewPage` + `DashboardSummary` + `CaseSummaryCard` + `RecentSearches`
- Search: 기존 Toolbar/Results/Progress
- Investigation Drawer: 변경 없음

### Navigation Flow

```text
Overview ──→ Search(상품검색) / Rental / Investigation / Analytics / System
Search ──→ History(하위) · 결과에서 Investigation 생성(기존)
Rental ──→ BackOffice API(기존) · Search Job 상태
Investigation ──→ Case List → Drawer
```

### Breadcrumb

AppShell 헤더는 「Search Crawler」 고정. 페이지별 eyebrow/title이 섹션 맥락을 제공.  
사이드바 accordion + 하위 활성 상태가 현재 위치를 나타냄.
