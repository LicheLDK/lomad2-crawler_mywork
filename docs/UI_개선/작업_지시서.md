# STEP MENU-01

당신은 Senior UX Designer이며 Front-end Architect입니다.

현재 Search Crawler Dashboard의 메뉴 구조를
운영 흐름에 맞게 개선합니다.

현재 기능은 변경하지 않습니다.

API도 변경하지 않습니다.

백오피스 연동도 변경하지 않습니다.

메뉴 구조만 리팩토링합니다.

목표

Search = 검색 실행

Rental = 계약 관리

Investigation = 조사 관리

Analytics = 통계

System = 시스템 관리

현재 기능은 그대로 유지합니다.

작업 완료 후

새 Menu Tree를 출력하고 멈춥니다.

# STEP MENU-09

전체 메뉴를 리팩토링합니다.

반드시 아래 원칙을 지킵니다.

1. Search는 검색 기능만 담당한다.

2. Rental은 계약 관리만 담당한다.

3. Investigation은 조사 관리만 담당한다.

4. Analytics는 분석만 담당한다.

5. Dashboard는 요약 화면만 담당한다.

6. System은 운영 관리만 담당한다.

7. 기존 API는 절대 변경하지 않는다.

8. BackOffice 연동은 그대로 유지한다.

9. URL은 최대한 유지한다.

10. 현재 구현된 기능은 삭제하지 않는다.
