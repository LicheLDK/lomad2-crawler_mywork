# UI Font System Upgrade

현재 Search Crawler Dashboard의 Typography를
현대적인 SaaS Dashboard 스타일로 개선합니다.

목표는
Linear, Vercel, Cursor, OpenAI Dashboard와 같은
깔끔하고 전문적인 UI를 만드는 것입니다.

## Font

Primary

- Pretendard Variable

Fallback

- Pretendard
- Inter
- system-ui
- sans-serif

Code Font

- JetBrains Mono

## Typography Scale

H1 : 32px / 700
H2 : 24px / 600
H3 : 20px / 600
H4 : 18px / 600

Body Large : 16px / 400
Body : 14px / 400
Caption : 12px / 400

Button : 14px / 500
Menu : 14px / 500

## Requirements

- Typography Token으로 관리한다.
- Tailwind Theme에 등록한다.
- 모든 화면에서 일관되게 적용한다.
- 숫자, 테이블, 카드, Drawer에서도 동일한 규칙을 사용한다.
- Bold 사용을 최소화하고 Weight 400~600 중심으로 구성한다.
- 기존 기능은 변경하지 않고 디자인 시스템만 개선한다.

작업 완료 후 Typography System과 적용 결과를 설명하고 종료한다.
