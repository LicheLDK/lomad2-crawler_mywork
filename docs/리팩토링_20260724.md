# Investigation Module 리팩토링 (2026-07-24)

## 개요

검색 결과에서 시작된 Investigation Case를 **Jira / Linear / GitHub Issues / Google Search Console** 스타일의 **Case Management System**으로 정리했습니다.

- 기존 디자인 시스템(ink / sand / teal) 유지
- 새 비주얼 테마를 만들지 않음
- Drawer 중심 작업, 검색 흐름 비차단

---

## 목표 원칙

| # | 원칙 | 구현 |
|---|------|------|
| 1 | 페이지 이동 최소화 | Case 상세 전용 라우트 없음. Drawer로 처리 |
| 2 | 대부분의 작업은 Drawer에서 | Workflow / Assignment / Notes / Evidence / Final Decision |
| 3 | 검색 흐름이 끊기지 않음 | `useStartInvestigation` → Toast + Drawer 오픈, 목록 페이지로 이동하지 않음 |
| 4 | Timeline으로 이력 확인 | 상태·담당·메모·판정·Evidence 등 이벤트 기록 |
| 5 | AI 분석이 항상 보임 | CaseDrawer Sticky Nav `AI` + 섹션 |
| 6 | Evidence 언제든 확인 | Sticky Nav `Evidence` (Timeline 아래) |
| 7 | 컴포넌트 재사용 | `features/investigation` 모듈 + barrel export |
| 8 | shadcn/ui 최대 활용 | Badge, Button, Card, Label, Separator, Timeline, ConfirmDialog |

## STEP 요약 (구현 순서)

| STEP | 내용 |
|------|------|
| 1 | Investigation 페이지 골격 (Header / Toolbar / Content) |
| 2 | Case Data Table + Filter + Row → Drawer |
| 3 | 검색 결과 **조사 시작** → Case 생성 (`CASE-YYYYMMDD-000001`), Toast, 페이지 이동 없음 |
| 4 | Investigation Detail Drawer (Case 메타 + 상품 정보) |
| 5 | AI Analysis Panel (유사도 Progress Bar + AI Score / 판단) |
| 6 | Evidence (원본 URL / 스크린샷 / 이미지 / OCR / HTML, 다운로드·삭제) |
| 7 | Timeline (시간순, shadcn Timeline) |
| 8 | Investigation Notes (Plain text, 작성·수정·삭제, 자동 저장) |
| 9 | Workflow (Open → Investigating → Review → Completed → Archived) |
| 10 | Assignment (담당자 / High·Medium·Low Badge / 마감일) |
| 11 | Final Decision (재판매 확인 / 추가 조사 / 오탐 / 제외 + Confirm Dialog → Completed) |
| 12 | Dashboard Investigation Summary Card |
| **FINAL** | `features/investigation` 모듈화 + 전역 Provider + Drawer 섹션 네비 |

## 주요 동작

### Case 생성 (검색)

1. 결과 카드 / Result Drawer에서 **조사 시작**
2. Case Number 자동 생성: `CASE-YYYYMMDD-000001`
3. Toast: `Investigation이 생성되었습니다.`
4. **페이지 이동 없음** → 전역 `CaseDrawer`로 바로 열 수 있음

### Workflow

```
Open → Investigating → Review → Completed → Archived
```

- Dropdown으로 **한 단계씩** 전진
- Completed 이후: Notes / Evidence / Assignment **수정 잠금** (Archived로만 이동 가능)
- Archived: 상태 변경 불가
- 상태 변경은 Timeline에 기록

### Final Decision

버튼: 재판매 확인 / 추가 조사 / 오탐 / 제외  
→ Confirmation Dialog → **Completed** + Timeline 기록

### Dashboard

- 기존 검색 `DashboardSummary`는 그대로 유지
- 하단에 `CaseSummaryCard`만 추가 (Open / Investigating / Review / Completed 건수)

## 후속 과제 (미진행)

이 문서 작성 시점 기준으로 다음 작업은 **의도적으로 진행하지 않음**.

- Investigation Case API / DB 연동 (현재 localStorage)
- 실제 OCR / HTML Snapshot 수집 파이프라인
- 담당자·조직도 서버 연동
- Case Detail 딥링크 (`?caseId=`) — 필요 시 최소 라우트만 추가
